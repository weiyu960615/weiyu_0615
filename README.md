本程式用於處理「桌遊體驗」與「電影欣賞」兩場活動的原始報名文字，透過清理半形空白與大小寫、保留原始與去重後的串列、利用集合（`set`）進行交集、聯集與雙向差集比較，並搭配字典（`dict`）查詢單價與保存人數、人次、應收金額摘要。
